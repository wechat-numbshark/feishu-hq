# 总部 OS Web 工作台

当前版本提供可运行的企业总部工作台，直接由 API 服务托管静态资源。

## 已实现界面

- 经营总览与管理决策区。
- AI 总部与常驻总部助理。
- 项目管理、客户与销售、人才与组织、财务管理、IT 与资产、知识与文件工作区。
- 全局命令搜索与快捷导航。
- 桌面、窄屏和手机响应式布局。
- AI 权限边界、系统连接状态和演示反馈。
- 品牌登录页、体验企业安全会话和退出登录。
- 管理设置、连接状态、租户信息和权限安全总览。
- 飞书接入向导、OAuth 状态、最小权限清单和组织同步操作。

## 视觉方向

采用宣纸白、墨色、飞书蓝与玉绿色构成的东方现代企业风格。界面以经营决策为首要任务，保持高信息密度，同时避免传统后台模板的机械感。

体验企业的身份、租户、经营指标、决策项和连接状态由 PostgreSQL 按租户读取；各业务明细表仍使用演示记录。正式飞书 OAuth、身份映射和组织同步代码已经完成，配置独立飞书应用后即可启用。
